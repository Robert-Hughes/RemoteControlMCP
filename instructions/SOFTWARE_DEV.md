General preferences for software development. Follow these unless the user specifies otherwise:

- Commit and push changes after each logical change.
- If the changes might contain personal information and the github repo is public, then do not push without confirmation.
- Commit messages should contain detailed bodies describing the rationale for the change, including the problem being solved, any investigations or evidence used and the reason for the chosen solution.
- Do not attempt to simulate mouse or keyboard inputs to test user interactions without confirmation.
